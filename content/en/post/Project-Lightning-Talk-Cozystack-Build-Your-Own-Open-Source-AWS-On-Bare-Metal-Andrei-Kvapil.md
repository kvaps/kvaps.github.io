Project Lightning Talk: Cozystack: Build Your Own Open Source AWS On Bare Metal - Andrei Kvapil, Maintainer

Hi! I’m Andrei, maintainer of Cozystack. Kubernetes and cloud infrastructure are the de facto standard. Many teams default to public clouds (AWS/GCP/Azure)—convenient, but not for everyone. Vendor lock-in, data control, and compliance push workloads to bare metal. i'll explain in a five minutes how Cozystack enables businesses to build open-source bare-metal infrastructure with cloud-like ease and zero vendor lock-in, while empowering service and hosting providers to compete with hyperscalers.
